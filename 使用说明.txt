《重生1988：南方创业记》试玩说明

开始游戏：将 index.html 与 assets 文件夹保持同级，打开 index.html。先选择出身和人物画像，再选一个行业开业。之后没有年度行动次数上限；每项安排按任务估算自然日并推进日历，跨年时按实际天数结账。精力条下方有“修整一天”按钮：推进一天并最多恢复50点精力；也可安排较长休整。1988至2026年每年会出现一条有史实来源的时代风向，提供稳健经营和主动进取两种应对；也可以先忙自己的生意，跨年后当年机会会过去。故事下方会显示四条后续行动建议，点击即可尝试；配置AI时会结合当前经营状态生成，未配置时使用本地建议。开局可选“标准经营”（D20判定成败）或“顺意叙事”（行动必成，仍需支付成本并承受市场波动）。

经营会消耗现金和精力。标准经营模式的行动卡会显示按当前属性计算的D20成功率，并以“偏难、尚可、较稳”提示风险；概率会随经营属性改变，不代表保证成功。结账会计算营收、经营盈余、场地杂费、家庭开销、工资、设备再投入和借款成本。进度自动保存在当前浏览器，也可使用存档菜单管理档位、导入或导出存档。游戏中的营收、租金、工资、借款、行情和事件数值均为模拟设计，并非真实店铺账本。

未设置 AI 时可以用本地估时、本地关键词与本地故事完整游玩。要启用 AI 耗时估算、自由行动识别、年度选择文案与叙事，“API设置”预填了 DeepSeek API 地址与模型名，也可改用其他 OpenAI 兼容服务；填写你自己的 API Key。模型为每项任务估算1至730天，并可为当前年度事件的两条固定路线生成标题与说明；日期逐日推进，跨年账目按实际天数折算。成本、骰点、成功失败和经营数值仍由本地规则裁定。密钥保存在当前浏览器；行动文字与必要经营状态会发送到你填写的服务商。固定行动通常每项调用一次耗时估算和一次故事；自由行动在一次请求里同时分类与估时，再调用一次故事。跨年结账并入该行动的故事，不另发请求。费用按你所选服务商的规则结算，本包不含 API Key，也不替用户购买或收费。耗时估算、分类或叙事请求失败时，游戏会分别退回本地估时、关键词识别和本地故事。使用 file:// 打开时，部分浏览器或服务商会阻止跨域请求；遇到这种情况，请通过 HTTP/HTTPS 网站或本地静态服务器打开。

首页横幅的“安排行动”快捷入口会随回合状态改为继续行动或年末结账，点击可直接定位到对应按钮。

网页客户版：将 index.html、pwa.js、sw.js、site.webmanifest 和 assets 文件夹部署到 HTTPS 静态网站，具体发布与手机桌面安装步骤见《网页发布与安装说明.txt》。AI 接口设置现有“测试接口”按钮；测试会向玩家填写的服务商发起一次请求，可能产生少量费用。AI 请求由玩家自己的 API 账号结算，游戏不代充、不代收。API Key 和存档分别保存在当前设备浏览器，换设备时需重新填 API Key 并导入存档。

首次打开游戏会提示玩家可直接开始，也可以先配置自己的 API。作者入口显示“土黄的梨”。意见反馈会打开本游戏的 GitHub Issues 页面；玩家需要登录 GitHub 后确认提交，反馈内容会公开展示，请勿填写 API Key 或个人隐私。
页面分为“接下来怎么做”和“眼前光景”两个独立页面，默认进入行动页；点上方标签切换。电脑、手机和平板固定在当前浏览器窗口，不需要整页上下翻找；内容较多时只在当前页面内滚动。手机上资金卡可横向浏览，行动卡按屏宽分列排列；自由行动框固定在底部，“人物”和“账本”可从顶部按钮查看。
