《重生1988：南方创业记》网页发布与安装

一、发布前保留这些文件
把 index.html、pwa.js、sw.js、site.webmanifest 和 assets 文件夹放在同一个网站根目录，并部署到 HTTPS 静态网站托管服务。可发布到 GitHub Pages 或其他支持静态文件的网站托管平台。请保留文件夹层级和相对路径。

仅双击 index.html 也能在电脑浏览器里预览，但 file:// 页面不能注册离线缓存，也不支持安装为 PWA；浏览器或 AI 服务商还可能限制跨域请求。客户使用时应分享 HTTPS 网页地址。

二、客户如何打开
电脑：用 Chrome、Edge 等浏览器打开网页地址。
安卓：用 Chrome 打开，选择“安装应用”或“添加到主屏幕”。
iPhone/iPad：用 Safari 打开，点“分享”后选择“添加到主屏幕”。
安装到桌面后仍是同一网页游戏，不需要分别维护 Windows、Android 和 iOS 三套程序。首次加载、AI 请求和存档同步以外的功能需要联网；首次打开后浏览器会缓存游戏页面与本地图片，AI 请求仍需联网。

三、玩家自备 API 与费用
1. 玩家在游戏顶部点“自备 API 设置”。
2. 填写自己选择的 OpenAI 兼容 API Base URL、模型名称和 API Key。
3. “测试接口”会发送一条简短模型请求，可能产生费用；测试通过后点“保存设置”。
4. 以后 AI 请求直接从玩家的浏览器发送到他填写的服务商。游戏不提供 API 额度、不代充，也不代收 AI 费用；服务商按其账户、模型和当期价格结算。
5. API Key 只保存在当前浏览器的本机存储中，不要在公共电脑保存。换浏览器或设备时需重新配置密钥。游戏存档也保存在本地浏览器，换设备时请先导出 JSON 存档再导入。

如果玩家不配置 API，仍可使用本地规则和本地故事游玩；AI 估时、自由行动识别和生成式叙事会使用本地备用内容。若服务商不允许网页跨域调用，测试会提示请求失败；此时需要支持浏览器跨域的 API 服务，或另建后端代理。

本发布包不包含任何玩家 API Key，也不包含 Windows 安装程序、Android APK 或 iOS App Store 安装包。
